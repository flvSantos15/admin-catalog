# Admin Catalogo

A comprehensive web-based platform designed to streamline industrial machinery maintenance and service order management. This full-stack application provides a complete solution for tracking equipment, scheduling maintenance, and managing service workflows in industrial environments.

## 🚀 Purpose

The main goal of this project is to manage service orders, track machine hours, monitor preventive maintenance, and streamline internal operations for industrial teams. It was developed to solve common issues in the field, such as delayed maintenance, lack of visibility, and poor communication between teams.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express, Prisma ORM, MongoDB
- **Authentication**: JWT, Middleware protected routes
- **DevOps & Tooling**: Docker, GitHub Actions, Husky, ESLint, Prettier
- **Testing**: Jest, Supertest
- **Observability**: Prometheus + Grafana (planned)
